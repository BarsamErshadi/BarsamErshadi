## Projects

### [Brawl Map Segmentation](https://github.com/BarsamErshadi/brawl-map-segmentation)
Synthetic-data pipeline that renders thousands of labelled game maps and trains a YOLO11 segmentation model to find walls and bushes, exported to ONNX. Built on the PylaAI trainer, which I improved and used to train my own model.

`Python` `YOLO11` `OpenCV` `NumPy` `Numba` `ONNX Runtime`

### [WireGuardVPN for Android](https://github.com/BarsamErshadi/WireGuardVPN-Android)
Native Android VPN client with WireGuard, stealth modes that tunnel traffic through a custom SOCKS5 bridge, encrypted server profiles and verified in-app updates.

`Kotlin` `Jetpack Compose` `Android VpnService` `WireGuard`
